# 화면 앱의 app 폴더는 하는 일로 나눈다

## 결정

화면 앱의 `app`(조립하는 쪽)은 하는 일마다 하위 폴더를 둔다(ADR 0005의 UI 앱을 더할 때 따른다):

- `start` — 시작·공급자 조립·환경 변수 읽기·오류 보고·전역 CSS
- `shell` — 틀·탭·위쪽 영역·화면 전환
- `routes` — 라우터·주소의 검색 값·디자인 시스템 링크에 꽂는 라우터 링크
- `pages` — 오류·없는 주소 같은 앱 공통 안내 화면
- 필요하면 `login`(로그인·세션 주인)·`version`(새 버전 알림·배포 뒤 옛 조각 복구)

## 이유

`app`은 앱이 커질수록 셸 부품·부팅 코드·라우터·안내 화면이 한 층에 쌓인다. 하는 일로 나누면 "탭은 어디서 그리나", "환경 변수는
어디서 읽나"에 폴더 이름이 답한다. 하위 폴더는 경계가 아니다(`app`은 한 레이어).
