# 설계 결정 기록 (ADR)

정한 결정과 그 이유를 한 결정에 한 파일로 남긴다. AGENTS.md의 결정 색인은 이 폴더에서 생성된다 — 손으로 고치지 않는다.

## 새 결정 추가

1. 다음 번호로 `NNNN-영문-슬러그.md`를 만든다.
2. 형식:

   ```md
   ---
   date: YYYY-MM-DD
   status: accepted
   ---

   # 한 줄 제목 (색인에 그대로 나간다 — 결정 자체를 말하게)

   ## 결정

   ## 이유
   ```

3. `git add`한 뒤 커밋하면 훅이 AGENTS.md 색인을 갱신해 함께 커밋한다. 색인은 git이 추적하는 ADR만 본다 — add하지 않은
   초안은 들어가지 않는다. 색인이 어긋나면 CI 테스트가 실패한다. ADR을 지우거나 `git mv` 없이 이름을 바꾼 커밋에서는 훅이
   돌지 않으니 `pnpm docs:index`를 직접 실행한다.

## 결정을 바꿀 때

기존 파일을 고쳐 쓰지 않는다. 새 결정을 추가하고, 옛 파일의 frontmatter를
`status: superseded`와 `superseded_by: NNNN`으로 바꾼다. 같은 결정의 사실 보정(날짜·출처·오타)은 고쳐도 된다.

외부 사실(한도·버전 지원 등)에는 출처 URL과 확인 날짜를 붙인다.
