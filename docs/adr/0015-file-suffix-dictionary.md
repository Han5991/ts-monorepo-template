# 화면 앱의 파일 접미사는 한 가지 일을 말한다

## 결정

화면 앱(ADR 0005의 UI 앱을 더할 때)의 순수 파일은 끝(접미사)으로 하는 일 하나를 말한다. 접미사가 없는 파일은 이름이 곧 내용이다.

- `*Presentation.ts` — 값을 화면의 글자·접근 이름·모양으로 옮긴다. 새로 판정하지 않는다.
- `*Form.ts` — 입력 상태와 그 검사, 보낼 값.
- `*Rules.ts` — 화면이 지금 무엇을 할 수 있는가(들어가는 길·버튼·단계).
- `*Url.ts` — 주소(검색 값·기록 항목)로 화면·시트를 여닫는 길.
- `*Memory.ts` — 화면을 떠나도 남기는 고른 값·입력.

엔티티의 사실을 판정하는 함수는 이 중 어디에도 두지 않는다 — 도메인 모듈이다(ADR 0010). 한 파일이 두 가지 일을 하면(판정과
주소 훅) 접미사마다 파일을 나눈다.

## 이유

역할을 폴더 대신 접미사로 말하면 한 화면 폴더 안에서 파일 이름만 보고 고를 수 있다. 같은 접미사가 파일마다 다른 뜻(어떤
`*Rules`는 시트 전체의 판단, 어떤 것은 버튼 표)이면 이름을 보고 고를 수 없으므로 뜻을 하나로 못 박는다.
