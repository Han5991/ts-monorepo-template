# 한 가지 일을 하고 문 하나로만 들어오는 작은 폴더는 하위 폴더로 나누지 않는다

## 결정

한 가지 일을 하고 밖에서 `index.ts` 하나로만 들어오는 폴더(공용 UI 부품 `ui`처럼)는 파일이 수십 개가 되기 전까지 평평하게 둔다.
화면 단위 나누기(ADR 0012)와 하는 일 나누기(ADR 0013)는 한 폴더에 여러 화면·여러 일이 섞일 때만 한다.

<!-- module:api:start -->

API 클라이언트(`@app/api-client`)도 같다.

<!-- module:api:end -->

## 이유

밖에서는 문 하나만 보이므로 안쪽 폴더는 찾는 데 도움이 되지 않고 깊이만 늘린다. 나누는 기준이 "섞여서 찾기 어렵다"이지 "파일이
많다"가 아니어야 폴더가 늘 의미를 갖는다.
